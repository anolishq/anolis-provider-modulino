# anolis-provider-modulino

An Anolis device provider for Arduino Modulino boards, built on modulino-driver
and the Rust provider SDK.

- [Boards](boards.md): each board type's signals and functions, and the state
  its outputs are put in at connect and at stop.
- [Hardware](hardware.md): wiring, host preparation, what happens to the
  outputs when the provider exits, and the hardware status: what has and has
  not run on real boards.
